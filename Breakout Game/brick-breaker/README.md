Brick Breaker (Godot)

This is a simple Brick Breaker / Breakout-style game implemented in GDScript.

How to run

1. Open Godot Engine (compatible with Godot 4.x; project file indicates 4.5 features).
2. In the Project Manager, click "Import" and select the `project.godot` file in this folder.
3. Open the project and press Play (F5). The main scene is `node_2d.tscn`.

Controls

- Left / Right arrow keys to move the paddle (or A / D if you remap input).
- Escape to restart when you win or lose.

Notes

- The main scene is `node_2d.tscn` and its script is `node_2d.gd`.
- This is a minimal implementation using ColorRect nodes for simplicity. You can replace them with Sprites or more complex scenes if you like.

Enjoy!
