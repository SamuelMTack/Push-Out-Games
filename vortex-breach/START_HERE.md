## 🆘 Getting Help

### Something Not Working?

**First, Check:**
1. SETUP_GUIDE.md > "Common Issues & Solutions"
2. QUICK_REFERENCE.md > "Troubleshooting"
3. Error message in Godot console

**Common Problems:**

❌ **"Invalid get index 'global_transform'"**
→ Camera3D must be child of Player

❌ **"Can't find Bullet.tscn"**
→ Make sure you created and saved Bullet.tscn

❌ **Player falls through floor**
→ Attach LevelGenerator.gd to LevelGenerator node

❌ **No enemies spawn**
→ Create and save Enemy.tscn
